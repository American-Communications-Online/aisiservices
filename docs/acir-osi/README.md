# ACIR-OSI Specification

ACIR-OSI grounds multi-model AI collaboration in verifiable public archives and human oversight.

## Concentric Ring Architecture

- **Center:** human judgment and final publication authority.
- **Round Robin core:** expands from `CCCGGLN` to `CCCDHGMX`. Engines synthesize and compare outputs against the outer rings.
- **Outer rings:** Open Source, Enterprise, and Government. Each cross-checks the core with independent perspectives.

## Intelligence Stack (8 tiers)

Scales from grounded human observation and public evidence, through multi-model synthesis, to planetary and deep-space coordination. Human review is required at every tier.

## Round Robin Logging Guidelines

1. Every model in `CCCDHGMX` answers the same prompt using the [comparison template](comparison-template.md).
2. Every claim links to a verifiable source (arXiv, GitHub, or Internet Archive).
3. Log model name, version, date, prompt, output, and reviewer.
4. Unsourced claims are marked `UNVERIFIED`; disagreements are recorded, not smoothed over.
5. A human reviewer signs off before publication.
